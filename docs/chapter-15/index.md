# Chapter 15: Final Projects

Congratulations! You've learned the fundamentals, intermediate concepts, and best practices. Now it's time to put everything together. In this chapter, we will build two complete projects.

## Learning Objectives

By the end of this chapter, you will be able to:

*   Plan and implement a **Command Line Interface (CLI) Tool**.
*   Build a **Web Scraper** to gather data from the internet.
*   Apply project structuring, error handling, and documentation practices.

## Chapter Overview

1.  **[CLI Tool Project](./cli-tool-project.md)**: A task manager for your terminal.
2.  **[Web Scraper Project](./web-scraper-project.md)**: Extracting headlines from a news site.
