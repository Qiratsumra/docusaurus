# Chapter 12: Data Handling & APIs

Data is at the core of most applications. In this chapter, we will learn how to read, write, and manipulate data in various formats, and how to interact with the outside world using APIs.

## Learning Objectives

By the end of this chapter, you will be able to:

*   Parse and generate **JSON** data.
*   Fetch data from the web using **REST APIs**.
*   Read and write **CSV and Excel** files.

## Chapter Overview

1.  **[Working with JSON](./working-with-json.md)**: The standard data format for the web.
2.  **[Interacting with APIs](./interacting-with-apis.md)**: Using the `requests` library.
3.  **[CSV and Excel](./csv-and-excel.md)**: Handling spreadsheet data.
