# Mastering Python Programming

This repository contains the source code for the book **"Mastering Python Programming: From Beginner to Advanced"**, built using [Docusaurus](https://docusaurus.io/).

## Book Structure

The content is organized into 15 chapters covering the entire spectrum of Python programming:

*   **Chapters 1-3**: Fundamentals (Intro, Data Types, Control Flow)
*   **Chapters 4-6**: Core Concepts (Functions, Modules, OOP)
*   **Chapters 7-9**: Robustness (File Handling, Errors, Exceptions)
*   **Chapters 10-12**: Intermediate & Data (Comprehensions, Generators, Decorators, Async, JSON, APIs)
*   **Chapters 13-15**: Professional Development (Project Structure, Testing, Best Practices, Final Projects)

## Getting Started

### Installation

1.  Install dependencies:
    ```bash
    npm install
    # or
    yarn
    ```

### Local Development

Start the local development server:

```bash
npm start
# or
yarn start
```

This opens a browser window at `http://localhost:3000`. Changes are reflected live.

### Build

Build the static website:

```bash
npm run build
# or
yarn build
```

The output will be in the `build` directory.

## Contributing

Content is located in the `docs/` directory. Each chapter has its own folder.
